手機版連招與機制

修正跳入連招少一層炸彈：現在是兩次普攻、跳躍命中、再普攻完成四層；跳躍未命中必須另補一擊，不能保證刷新逃離。

炸彈快速疊滿

3技放炸彈 → 1技加攻速 → 普攻疊層 → 普攻疊層 → 普攻疊層 → 滿層爆炸

先放三技再開一技，用四次普攻快速引爆。敵方準備反打時應邊走邊疊，不要為了最後一層站在控制範圍內。

四層炸彈確認後收割

3技放炸彈 → 1技提升攻速 → 普攻第1層 → 普攻第2層 → 2技落地命中第3層 → 普攻第4層引爆 → 確認重置後跳出

跳躍必須命中帶炸彈的英雄才增加這一層；沒命中要再補一次有效攻擊。只有確認四層爆炸或參與擊殺達成重置後才能再跳，敵方控制還在時不預設能安全跳入。

反刺客擊退

4技擊退 → 3技標記 → 1技加攻速 → 拉開普攻 → 2技撤退

敵方貼身時先用大絕拉開，再放炸彈與一技反打；火箭跳躍保留穿牆或遠離下一次突進，不必為了追擊交掉自保技能。

實戰節奏

前期

崔絲塔娜前期射程較短，先以穩定補刀和爆炸射擊被動清線為主。對手走位失誤時，先把三技放在英雄或防禦塔，再開一技用普攻與技能疊滿四層；二技是唯一位移，沒有確定擊殺、炸彈重置或敵方關鍵技能已交時，不要主動跳進去。

中期

雲陶與無盡成形後，多明尼克第三件補穿甲；先在安全位置用炸彈加攻速打滿層，再判斷是否跳入。只有滿層炸彈在英雄身上引爆或參與擊殺等重置條件達成，才有第二次跳躍；推塔同樣先看側翼。

後期

被動讓普攻、爆炸射擊與毀滅射擊射程隨等級增加，後期應站在前排後方安全輸出。三技搭配一技快速疊滿是主要單體爆發；大絕優先擊退刺客或把威脅推離自己，只有能確定擊殺時才拿來收尾。

對局與隊伍配合

法洛士能大絕攔跳，庫奇可中距離削防換血，凱莎可跟進；敵方還保有控制時，不預設能靠炸彈重置跳回來。 威脅名單採同分路指南，較有利名單保留機制判斷並移除與威脅名單重疊者；現有輔助組合逐項複核技能互動後保留。

雙人線配合

下列輔助配合以技能互動為依據。銳兒、雷歐娜、亞歷斯塔仍可配合本頁打法；先確認對手輔助的控制與兩邊召喚師技能，單一射手對局不代表必勝。

輔助配合

銳兒

範圍控制能讓崔絲塔娜安全疊滿炸彈，擊殺後也容易重置跳躍。

雷歐娜

二級強開與崔絲塔娜爆發非常契合，適合快速建立擊殺優勢。

亞歷斯塔

擊飛與回推能固定目標，並替崔絲塔娜承擔進場後的反打壓力。

依陣容調整配置

依崔絲塔娜的炸彈疊層與高攻速普攻路線選擇替換；先看實際死亡與傷害不足原因。

高生命／高防禦前排

依敵方前排成形調整

觸發：敵方前排已形成高生命或高防禦，正面輸出受阻。

換裝原則

崔絲塔娜保留前述五成裝加獨立鞋線；同一格不同情境擇一替換，不全部加購。

先保留預設穿甲核心，單一裝備格的調整不代表重買另一套。

刺客／瞬間爆發

保命格可提早

觸發：被同一輪突進秒殺，無法打出主要技能與普攻。

被物理集火時保留復活機會

嗜血者 → 守護天使

主要死亡原因是刺客或突進一次切入，且隊友能掩護復活位置。

嗜血者整格換守護天使，犧牲部分炸彈疊層與高攻速普攻或持續防禦；復活後無人接應時先改善站位。

魔法爆發改魔提斯

嗜血者 → 魔提斯深淵

敵方主要擊殺來源是魔法爆發，且尚未裝另一件生命線裝備。

以嗜血者換魔提斯處理魔法爆發；不把魔防誤當通用抗物理方案。

復活與魔法生命線處理的傷害不同，按實際威脅擇一；盾弓與魔提斯不重複保留。

控制鏈

先判斷控制能否解除

觸發：可解除的禁錮、暈眩等控制反覆中斷輸出。

關鍵控制用主動解控

嗜血者 → 水星彎刀

可解除的控制反覆讓自己無法輸出，且閃現不能解決。

以嗜血者換水星彎刀；主動要手動使用，不能解除擊飛或擊退，也不是舊版附魔。

水星彎刀是成裝，不佔鞋子升級；擊飛、擊退須靠預先走位或隊友保護。

治療／吸血

治療已影響集火時

觸發：敵方持續治療抵銷集火，且團隊缺乏穩定重創。

重創取代最大化穿甲收益

多明尼克的問候 → 致死宣告

敵方治療或吸血持續影響勝負，隊友無法穩定施加重創。

致死宣告替換多明尼克；保留暴擊、穿甲與重創，不並排買兩件。

需要時先用死刑宣告過渡；不要把所有敵方英雄都當成必出重創的理由。

反覆大型護盾

團隊無其他反盾者才承擔

觸發：大量反覆護盾持續阻止集火，且自己能穩定命中目標。

必要時補巨蛇鋒牙

嗜血者 → 巨蛇鋒牙

隊友無法施加反盾，且護盾確實抵銷主要輸出。

嗜血者換巨蛇鋒牙會犧牲原末段功能；崔絲塔娜仍需保留主要輸出核心，只有單一小護盾時不換。

反盾屬團隊分工，不為一個小盾放棄整條普攻或技能路線。
