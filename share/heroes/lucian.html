手機版連招與機制

修正錯誤符文對應，穿兵一技後若能安全普攻就先打雙槍；遠距 Q 接 W 僅在無法普攻時使用，避免無條件覆蓋被動。

基礎短換血

3技調位 → 被動雙槍 → 1技貫穿 → 被動雙槍 → 2技標記 → 被動雙槍

位移後把每次被動雙槍打完整，再銜接下一個技能；若敵方控制未交，三技改成橫向或向後使用。

穿兵安全消耗

1技穿過士兵 → 2技遠距標記 → 普攻觸發加速 → 3技撤離

只有目標在普攻範圍外時，才用穿兵一技接遠距二技消耗；進入安全普攻範圍後，每次技能之間先打完被動雙槍，避免直接用下一個技能覆蓋尚未消耗的被動。三技優先撤離。

團戰連射轉火

3技進入射程 → 被動雙槍 → 2技 → 被動雙槍 → 1技 → 被動雙槍 → 4技追擊收尾

每組雙槍都會縮短三技冷卻，讓路西恩能再次調整位置；大絕適合敵人撤退或自己無法安全普攻時使用。

實戰節奏

前期

路西恩的優勢來自每次施放技能後接上光之獵手雙槍，任何只丟技能不接普攻的換血都會浪費傷害。利用鋒芒貫穿穿過士兵消耗，冷酷進擊不要固定往前交；敵方控制仍在時，短位移更適合橫向躲招或撤退。

中期

奪魄之鐮與狂暴利刃成形後，以技能、雙槍交替完成短換血，利用充能跑速重新拉開；多明尼克第三件補穿甲。每組雙槍縮短三技冷卻，敵方硬控未交時位移橫向使用。

後期

後期面對長射程陣容時不要強行正面貼近，先用赤色屠戮壓低血量或逼走位，再尋找安全窗口輸出。位移要優先保命，攻擊最近的安全目標；只有確認敵方關鍵控制已交，才向前追擊。

對局與隊伍配合

法洛士與艾希可先在射程外緩速控場；煞蜜拉能擋關鍵飛行道具，等對手防護交掉再用雙槍交換，不把短位移固定向前。 威脅名單採同分路指南，較有利名單保留機制判斷並移除與威脅名單重疊者；現有輔助組合逐項複核技能互動後保留。

雙人線配合

下列輔助配合以技能互動為依據。娜米、布郎姆、米里歐仍可配合本頁打法；先確認對手輔助的控制與兩邊召喚師技能，單一射手對局不代表必勝。

輔助配合

娜米

增傷、治療與控制能直接配合路西恩短連射，是最穩定的壓線組合。

布郎姆

路西恩能快速疊滿震盪猛擊，近距離換血與反打能力都很強。

米里歐

增程與護盾讓路西恩更容易安全打完技能穿插普攻的爆發。

依陣容調整配置

依路西恩的技能後雙槍與魔法彎刀強化普攻路線選擇替換；先看實際死亡與傷害不足原因。

高生命／高防禦前排

依敵方前排成形調整

觸發：敵方前排已形成高生命或高防禦，正面輸出受阻。

換裝原則

路西恩保留前述五成裝加獨立鞋線；同一格不同情境擇一替換，不全部加購。

先保留預設穿甲核心，單一裝備格的調整不代表重買另一套。

刺客／瞬間爆發

保命格可提早

觸發：被同一輪突進秒殺，無法打出主要技能與普攻。

被物理集火時保留復活機會

嗜血者 → 守護天使

主要死亡原因是刺客或突進一次切入，且隊友能掩護復活位置。

嗜血者整格換守護天使，犧牲部分技能後雙槍與魔法彎刀強化普攻或持續防禦；復活後無人接應時先改善站位。

魔法爆發改魔提斯

嗜血者 → 魔提斯深淵

敵方主要擊殺來源是魔法爆發，且尚未裝另一件生命線裝備。

以嗜血者換魔提斯處理魔法爆發；不把魔防誤當通用抗物理方案。

復活與魔法生命線處理的傷害不同，按實際威脅擇一；盾弓與魔提斯不重複保留。

控制鏈

先判斷控制能否解除

觸發：可解除的禁錮、暈眩等控制反覆中斷輸出。

關鍵控制用主動解控

嗜血者 → 水星彎刀

可解除的控制反覆讓自己無法輸出，且閃現不能解決。

以嗜血者換水星彎刀；主動要手動使用，不能解除擊飛或擊退，也不是舊版附魔。

水星彎刀是成裝，不佔鞋子升級；擊飛、擊退須靠預先走位或隊友保護。

治療／吸血

治療已影響集火時

觸發：敵方持續治療抵銷集火，且團隊缺乏穩定重創。

重創取代最大化穿甲收益

多明尼克的問候 → 致死宣告

敵方治療或吸血持續影響勝負，隊友無法穩定施加重創。

致死宣告替換多明尼克；保留暴擊、穿甲與重創，不並排買兩件。

需要時先用死刑宣告過渡；不要把所有敵方英雄都當成必出重創的理由。

反覆大型護盾

團隊無其他反盾者才承擔

觸發：大量反覆護盾持續阻止集火，且自己能穩定命中目標。

必要時補巨蛇鋒牙

嗜血者 → 巨蛇鋒牙

隊友無法施加反盾，且護盾確實抵銷主要輸出。

嗜血者換巨蛇鋒牙會犧牲原末段功能；路西恩仍需保留主要輸出核心，只有單一小護盾時不換。

反盾屬團隊分工，不為一個小盾放棄整條普攻或技能路線。
