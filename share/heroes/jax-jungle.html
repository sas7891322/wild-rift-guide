被動

無情突擊

連續普攻會逐步提高攻速，持續作戰越久越強。

1 技

跳斬

跳向指定單位造成物理傷害，可用於追擊、撤退或跳友軍。

2 技

蓄力一擊

強化下一次普攻造成額外魔法傷害並重置普攻。

3 技

反擊風暴

短暫閃避所有普攻並減少範圍技能傷害，結束時暈眩附近敵人。

4 技

武器專精

被動每第三次普攻造成額外魔法傷害；主動提高物防與魔防。

COMBOS

常用連招

蓄暈 Gank

開啟3技 → 1技跳斬 → 二段3技暈眩 → 普攻 → 2技重置

先開反擊風暴再跳向敵人，讓暈眩更難躲；接普攻與二技重置完成爆發。

野區單挑

4技增防 → 3技閃避 → 普攻 → 2技 → 1技追擊

大絕與反擊風暴用來承受第一輪輸出，持續普攻疊攻速；跳斬保留追擊或跳眼撤退。

切後排長打

1技進場 → 4技 → 普攻 → 2技重置 → 3技 → 持續普攻

跳入後立刻開大提高耐久，二技重置普攻；反擊風暴留給敵方射手的主要輸出窗口。

GAME PLAN

實戰節奏

前期

二技重置普攻並配合被動攻速可穩定清野，三技用來減少野怪普攻與處理河道交戰。Gank 時先蓄反擊風暴再跳斬，成功率比直接跳臉更高。

中期

三相之力與續戰裝成形後，入侵、單抓與物件輸出都很強。利用跳斬穿過友軍或視野單位調整位置，面對普攻型核心時把三技留到對方輸出窗口。

後期

可選擇側翼切後排或保護己方核心。主動大絕提高雙防後再進場，持續普攻疊攻速；不要在反擊風暴結束後仍留在多人集火中心。

ADAPTIVE BUILD

依對局調整

打野先維持標準刷野與節奏裝，只有敵方陣容或我方前排需求明顯時才調整。

坦克多高優先

觸發：敵方前排多，物件團與正面團戰會長時間卡在高生命目標上。

  • 高生命目標敵方前排生命明顯高於你，而標準符文沒有斷切時。

    斷切能直接提高對高生命敵人的普攻傷害。

刺客／爆發多高優先

觸發：敵方能在你進場或搶物件前快速把你秒掉。

  • 魔法爆發威脅敵方法師／AP刺客的單次爆發才是主要死亡來源時。

    魔提斯深淵提供魔防與低血量魔法護盾，比單純增加輸出更能保住進場或持續輸出。

  • 爆發對局符文對面主要靠短時間連段把你秒掉，而且目前標準符文沒有骨甲時。

    骨甲直接降低同一名敵人接續幾次技能或普攻的傷害。

控制多高優先

觸發：進場或搶物件時經常被控制鏈直接中斷節奏。

  • 關鍵硬控解法敵方有 1～2 個關鍵硬控，只要命中就可能直接死亡時，將後期彈性位改成水星彎刀。

    先購買水銀飾帶取得主動解控，之後再合成水星彎刀；水銀飾帶是合成組件，不是另一件要與水星彎刀互換的成裝。

  • 重控制陣容控制來源很多，不是只靠一次主動解控就能解決時。

    犧牲部分輸出型傳奇符文，換取韌性與緩速抗性。

治療／吸血多中優先

觸發：敵方前排、鬥士或吸血核心能在物件團長時間回復。

  • 重創需求敵方有多名高治療／高吸血英雄，或核心前排能在團戰中大量回血時。

    生化龐克鏈鋸之劍提供物攻、生命與技能加速，適合近戰物理角色補重創。

我方缺前排中優先

觸發：我方陣容沒有可靠第一承傷點，團戰需要有人更早進場吸收注意力。

  • 維持標準配置

    若標準配置已經有半坦容錯，就不必再犧牲核心傷害。

提醒：「缺前排」不代表所有打野都要改坦裝；刺客、法師與射手打野硬轉坦通常會失去英雄價值。
