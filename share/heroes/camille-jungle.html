被動

適性防禦

普攻英雄時依目標主要傷害類型獲得物理或魔法護盾。

1 技

精密解剖

強化下一次普攻並提高跑速；延遲後再次施放可造成更高傷害，其中一部分轉為真實傷害。

2 技

刀光掠影

向前方扇形橫掃，外圈造成更高傷害、緩速敵人並治療自身。

3 技

鋼鐵鉤射

射出鉤索拉向牆體，再次施放可跳向指定方向；命中英雄時增加攻速。

4 技

海克斯晶體結界

跳向指定英雄使其無法逃出結界，並擊退附近其他敵人。

COMBOS

常用連招

牆鉤換血

一段3技 → 二段3技 → 普攻 → 一段1技 → 2技外圈 → 二段1技

鉤牆暈眩後穿插一段一技，退開時用二技外圈回血，再回身打出真實傷害。

大絕單抓

3技 → 4技 → 普攻 → 一段1技 → 2技 → 二段1技

先用三技逼位移，再以大絕封鎖逃生路線，等待二段一技完成主要爆發。

蓄二段進場

一段1技 → 一段3技 → 二段3技 → 4技 → 二段1技

先對小兵打出一段一技，再利用牆鉤進場，確保二段一技能快速打到核心目標。

GAME PLAN

實戰節奏

前期

清野時利用一技重置普攻並等待二段真實傷害，三技盡量留給跨牆 Gank 或逃離入侵。選擇靠牆且隊友有控制的路線，成功率遠高於從河道直線進場。

中期

三相之力成形後單抓與小規模戰鬥最強。物件前可用牆鉤從側翼進場，再用大絕封鎖敵方核心位移，讓隊友集中火力。

後期

不要把自己當成主坦；先在側翼等待核心目標露出，再用三技和大絕隔離。若無法切後排，就用大絕躲關鍵技能並限制敵方刺客。

ADAPTIVE BUILD

依對局調整

打野先維持標準刷野與節奏裝，只有敵方陣容或我方前排需求明顯時才調整。

坦克多高優先

觸發：敵方前排多，物件團與正面團戰會長時間卡在高生命目標上。

  • 高生命目標敵方前排生命明顯高於你，而標準符文沒有斷切時。

    斷切能直接提高對高生命敵人的普攻傷害。

刺客／爆發多高優先

觸發：敵方能在你進場或搶物件前快速把你秒掉。

  • 魔法爆發威脅敵方法師／AP刺客的單次爆發才是主要死亡來源時。

    魔提斯深淵提供魔防與低血量魔法護盾，比單純增加輸出更能保住進場或持續輸出。

  • 爆發對局符文對面主要靠短時間連段把你秒掉，而且目前標準符文沒有骨甲時。

    骨甲直接降低同一名敵人接續幾次技能或普攻的傷害。

控制多高優先

觸發：進場或搶物件時經常被控制鏈直接中斷節奏。

  • 關鍵硬控解法敵方有 1～2 個關鍵硬控，只要命中就可能直接死亡時，將後期彈性位改成水星彎刀。

    先購買水銀飾帶取得主動解控，之後再合成水星彎刀；水銀飾帶是合成組件，不是另一件要與水星彎刀互換的成裝。

  • 重控制陣容控制來源很多，不是只靠一次主動解控就能解決時。

    犧牲部分輸出型傳奇符文，換取韌性與緩速抗性。

治療／吸血多中優先

觸發：敵方前排、鬥士或吸血核心能在物件團長時間回復。

  • 重創需求敵方有多名高治療／高吸血英雄，或核心前排能在團戰中大量回血時。

    生化龐克鏈鋸之劍提供物攻、生命與技能加速，適合近戰物理角色補重創。

我方缺前排中優先

觸發：我方陣容沒有可靠第一承傷點，團戰需要有人更早進場吸收注意力。

  • 維持標準配置

    若標準配置已經有半坦容錯，就不必再犧牲核心傷害。

提醒：「缺前排」不代表所有打野都要改坦裝；刺客、法師與射手打野硬轉坦通常會失去英雄價值。
