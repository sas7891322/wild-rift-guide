COMBOS

常用連招

嘲諷拉刀 Gank

3技嘲諷 → 1技召回利刃 → 強化普攻 → 強化普攻 → 2技劍陣

三技先控制，召回利刃穿過敵人取得強化，再打出普攻；二技在敵方開始反擊時開啟。

閃現延長嘲諷

3技衝刺 → 途中閃現調整 → 1技 → 三次強化普攻 → 2技

三技途中閃現可延長或改變嘲諷路線，適合抓後排；需先在練習模式熟悉距離。

大絕反打支援

4技保護隊友 → 落地3技嘲諷 → 1技 → 2技格擋 → 強化普攻

優先大絕給正在被集火的主力，落地後嘲諷追擊者並用劍陣擋普攻，形成完整反打。

GAME PLAN

實戰節奏

前期

一技強化普攻對野怪有額外效率，靈氣利刃穿過目標時可提高攻速與傷害。Gank 時用三技嘲諷後召回利刃，讓刀刃穿過敵人，再完成三次強化普攻。

中期

大絕讓慎能在刷野或反蹲時立即支援另一側戰場，施放前先確認物件是否會因此失去。傳送落地後用三技接控制，二技劍陣保護正在輸出的隊友。

後期

可留在側翼處理視野或吸引敵人，再用大絕加入主戰場。正面團戰則用二技擋住大量普攻與命中效果，三技優先控制後排或反開敵方刺客。

ADAPTIVE BUILD

依對局調整

打野先維持標準刷野與節奏裝，只有敵方陣容或我方前排需求明顯時才調整。

坦克多高優先

觸發：敵方前排多，物件團與正面團戰會長時間卡在高生命目標上。

  • 前排處理敵方至少有 2 名高生命／高抗性前排，而且團戰多數時間必須先打前排時。

    前排本身不需要硬轉全輸出，改用能隨目標生命造成持續傷害的防裝處理長戰。

刺客／爆發多高優先

觸發：敵方能在你進場或搶物件前快速把你秒掉。

  • 暴擊物理爆發敵方主要物理輸出依賴暴擊普攻時。

    蘭頓之兆提供高額物防並降低暴擊傷害。

  • 持續魔法爆發敵方主要傷害集中在多段魔法技能時。

    自然之力在持續承受魔法技能後提供更高的魔法承傷能力。

控制多高優先

觸發：進場或搶物件時經常被控制鏈直接中斷節奏。

  • 韌性鞋線敵方控制密集，且魔法傷害／控制鏈是主要威脅時。

    改走水星之靴→鎖鏈軍靴，直接補韌性與魔防。

  • 控制鏈承傷你是主要進場點，會連續吃到硬控時。

    堅毅讓被控期間更耐打，適合前排承接第一波技能。

治療／吸血多中優先

觸發：敵方前排、鬥士或吸血核心能在物件團長時間回復。

  • 維持標準配置

    標準配置已經有重創，維持即可。

我方缺前排中優先

觸發：我方陣容沒有可靠第一承傷點，團戰需要有人更早進場吸收注意力。

  • 維持標準配置

    你本來就是隊伍前排，維持標準坦裝並把資源用在正確抗性即可。

提醒：「缺前排」不代表所有打野都要改坦裝；刺客、法師與射手打野硬轉坦通常會失去英雄價值。
