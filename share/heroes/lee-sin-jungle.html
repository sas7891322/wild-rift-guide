被動

無雙亂舞

施放技能後，接下來兩次普攻會獲得額外攻速並回復能量。清野與持續作戰時應讓技能和普攻交錯，避免一次把技能全部按完。

1 技

虎嘯龍吟／震驚百里

第一段發出音波，對第一個命中的敵人造成物理傷害並揭露目標；命中後可再次施放，突進至目標並依其已損失生命提高傷害。

2 技

鐵璧金身／易筋洗髓

第一段向指定位置衝刺，落點附近有敵方英雄或野怪時獲得護盾；第二段強化接下來的攻擊，造成額外魔法傷害並提供全能吸血。普攻可縮短第一段冷卻。 7.2b 護盾提高至 100/160/220/280，全能吸血提高至 20/30/40/50%。

3 技

狂風暴雨／分筋錯骨

第一段重擊地面，對附近敵人造成魔法傷害並揭露位置；命中後可再次施放，使受到第一段影響的敵人緩速，效果會隨時間逐漸恢復。

4 技

神龍擺尾

猛踢一名敵方英雄，造成物理傷害並將其擊退。被踢飛的目標撞上其他敵人時，會對沿途敵人造成傷害並擊飛，是開戰、保排與搶角度的核心技能。

COMBOS

常用連招

基礎追擊連招

1技第一段 → 1技第二段 → 普攻 → 3技第一段 → 普攻 → 3技第二段

一技命中後突進，穿插被動普攻再用三技緩速。適合一般 Gank 與追擊，但二段一技前要先確認敵方沒有把你帶進危險位置。

踢回隊伍

1技第一段 → 1技第二段 → 2技繞到身後 → 4技踢回 → 3技緩速

先用一技接近，再用二技穿到目標身後，把敵人踢向隊友。二技落點必須先看清楚，避免角度不足反而把目標踢走。

大絕接二段一技

1技第一段 → 4技擊退 → 1技第二段 → 3技第一段 → 普攻 → 3技第二段

先用一技標記目標，再以大絕擊退並立刻用二段一技跟進，能同時完成位移控制與斬殺追擊。施放前要確認落點不會讓自己脫離隊友。

GAME PLAN

實戰節奏

前期

善用每次施放技能後的兩次強化普攻維持能量與清野效率。第一輪清野後優先觀察有控制或敵方壓線的路線，並利用前期單挑能力爭奪河蟹與入侵機會。

中期

物件刷新前先搶河道視野與側翼角度；一技命中後不要急著二段進場，先確認隊友距離、敵方控制與二技退路，再決定追擊或用大絕製造人數差。7.2b 二技續戰增強後可承受更長的小規模戰鬥，但二段一技進場前仍要保留撤退角度。

後期

後期傷害優勢會下降，重點改為尋找神龍擺尾的關鍵角度。可踢回敵方核心、踢開切入者保護後排，並保留重擊處理飛龍與巴龍。

ADAPTIVE BUILD

依對局調整

打野先維持標準刷野與節奏裝，只有敵方陣容或我方前排需求明顯時才調整。

坦克多高優先

觸發：敵方前排多，物件團與正面團戰會長時間卡在高生命目標上。

  • 維持標準配置

    標準配置已經具備足夠打坦能力，維持核心即可。

刺客／爆發多高優先

觸發：敵方能在你進場或搶物件前快速把你秒掉。

  • 魔法爆發威脅敵方法師／AP刺客的單次爆發才是主要死亡來源時。

    魔提斯深淵提供魔防與低血量魔法護盾，比單純增加輸出更能保住進場或持續輸出。

  • 爆發對局符文對面主要靠短時間連段把你秒掉，而且目前標準符文沒有骨甲時。

    骨甲直接降低同一名敵人接續幾次技能或普攻的傷害。

控制多高優先

觸發：進場或搶物件時經常被控制鏈直接中斷節奏。

  • 關鍵硬控解法敵方有 1～2 個關鍵硬控，只要命中就可能直接死亡時，將後期彈性位改成水星彎刀。

    先購買水銀飾帶取得主動解控，之後再合成水星彎刀；水銀飾帶是合成組件，不是另一件要與水星彎刀互換的成裝。

  • 重控制陣容控制來源很多，不是只靠一次主動解控就能解決時。

    犧牲部分輸出型傳奇符文，換取韌性與緩速抗性。

治療／吸血多中優先

觸發：敵方前排、鬥士或吸血核心能在物件團長時間回復。

  • 重創需求敵方有多名高治療／高吸血英雄，或核心前排能在團戰中大量回血時。

    生化龐克鏈鋸之劍提供物攻、生命與技能加速，適合近戰物理角色補重創。

我方缺前排中優先

觸發：我方陣容沒有可靠第一承傷點，團戰需要有人更早進場吸收注意力。

  • 維持標準配置

    這隻英雄不適合為了「缺前排」硬改成主坦；維持自己的輸出／功能，讓巴龍路或輔助補前排更合理。

提醒：「缺前排」不代表所有打野都要改坦裝；刺客、法師與射手打野硬轉坦通常會失去英雄價值。
