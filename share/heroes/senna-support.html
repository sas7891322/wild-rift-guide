被動

赦罪

附近單位陣亡時有機會生成黯霧靈魂；攻擊靈魂可永久提高物攻、攻擊距離與暴擊率。對同一英雄完成兩次攻擊也能抽取黯霧並造成目前生命傷害。

1 技

刺骨幽闇

向指定單位射出穿透光束，傷害敵人並治療自己與友軍；普攻可縮短冷卻，且技能能作用於士兵、守衛與防禦塔來延伸射程。

2 技

終末之擁

射出黑霧命中第一個敵人並造成傷害，短暫延遲後禁錮目標與周圍敵人；若命中單位死亡則會立即觸發。

3 技

黯霧詛咒

化為黯霧並提高跑速，附近友軍進入後會獲得偽裝與幽魂外觀，適合轉線、撤退與掩護隊友進場。

4 技

黎明之影

向全圖發射光影波，為所有友方英雄提供護盾，並對中央路徑上的敵人造成物理傷害與附加黯霧。

COMBOS

常用連招

抽魂治療換血

第一次普攻命中英雄 → 1技傷害並治療隊友 → 被動抽取黯霧 → 利用射程拉開 → 安全時補普攻

普攻接一技可快速完成兩次命中抽魂，一技同時回復自己與射手，完成換血後立即退回安全距離。

禁錮集火

2技命中敵人或殘血單位 → 普攻壓低目標 → 延遲或立即觸發禁錮 → 1技穿透輸出與治療 → 虛弱主要反打者

二技命中的單位若死亡會立即展開禁錮，可利用殘血士兵或召喚物製造更難反應的控制。

全圖護盾反打

4技提前提供全圖護盾 → 3技掩護隊伍進場 → 2技限制敵方走位 → 1技治療與輸出 → 遠距普攻持續輸出

大絕護盾要在敵方爆發落下前抵達；抵達戰場後以三技掩護隊友，再用二技與一技延續戰鬥。

GAME PLAN

實戰節奏

前期

讓射手穩定補刀，自己利用普攻接刺骨幽闇完成兩次命中抽取黯霧，並收集士兵死亡後產生的靈魂。靈魂落在危險位置時不要勉強撿取；一技可穿過士兵、隊友或守衛同時治療與消耗，終末之擁則留給敵方補刀或走位受限的瞬間。

中期

跟著隊伍移動收集兵線、野區與戰鬥產生的黯霧，物件戰站在前排後方，以一技同時治療隊友與消耗敵人。二技命中後協助集火，三技可掩護隊伍轉線或撤退；持續觀察全圖，用黎明之影提前替遠端戰鬥提供護盾。

後期

靈魂帶來長射程後，攻擊最近且安全的目標即可，不必為點後排向前。敵方突進時用二技與虛弱保護主力，一技持續治療。大絕應在爆發落下前施放，讓全隊先獲得護盾，並盡量讓中央傷害路徑穿過主要目標。

ADAPTIVE BUILD

依對局調整

輔助調整以團隊承傷、解控與保護主力為優先，不為了單一敵人破壞整套功能裝。

物理傷害多高優先

觸發：敵方主要輸出集中在射手、物理刺客或普攻型英雄。

  • 維持標準配置

    標準配置已有守護天使或其他物理容錯，維持即可。

魔法傷害多高優先

觸發：敵方主要威脅來自法師、AP刺客或大量範圍魔法傷害。

  • 魔法爆發自保敵方AP爆發是主要死亡來源時。

    魔提斯深淵的魔防與魔法護盾能讓物理輔助撐過第一輪。

控制多最高優先

觸發：敵方硬控能直接抓死己方主力，或你進場後會被連續控制。

  • 關鍵硬控解法敵方有 1～2 個關鍵硬控，只要命中就可能直接死亡時，將後期彈性位改成水星彎刀。

    先購買水銀飾帶取得主動解控，之後再合成水星彎刀；水銀飾帶是合成組件，不是另一件要與水星彎刀互換的成裝。

  • 重控制陣容控制來源很多，不是只靠一次主動解控就能解決時。

    犧牲部分輸出型傳奇符文，換取韌性與緩速抗性。

提醒：米凱主要替隊友解控；水星彎刀則是物理英雄自我解控，兩者角色不同。

治療／吸血多中優先

觸發：敵方有大量治療、吸血或回復，讓己方集火很難完成擊殺。

  • 維持標準配置

    標準配置已經有重創，不必重複購買。

我方主力需要保護高優先

觸發：己方只有一個主要輸出點，且敵方每波團戰都會集中切入他。

  • 維持標準配置

    姍娜本身已有治療、控制與全圖支援能力；不必為了保排硬轉完整軟輔裝，保留自己的遠程輸出與功能更合理。

提醒：保排調整看己方陣容，不是看到敵方刺客就把所有功能裝都換成防裝。
