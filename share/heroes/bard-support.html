被動

旅者引領

收集調和之音可獲得經驗、魔力與脫離戰鬥跑速，並逐步強化米普。米普會協助普攻，之後可造成範圍傷害與緩速。

1 技

宇宙制約

發射能量彈造成魔法傷害與緩速；若第一個目標後方再碰到另一名敵人或牆面，兩者都會被暈眩。

2 技

守望神龕

在地面放置可充能的神龕，友軍踏上後回復生命並獲得短暫跑速。敵方踩到會摧毀神龕。

3 技

奇幻旅程

在牆體上建立單向傳送通道，所有英雄都能通過。可用來遊走、繞後或撤退，但敵人也能跟進。

4 技

凝滯命域

對指定區域施放能量，使範圍內所有單位短暫進入凝滯，期間無法行動、受到傷害或被指定。可影響英雄、野怪與防禦塔。

COMBOS

常用連招

米普緩速接暈眩

米普普攻先緩速 → 1技射向牆面或第二目標 → 普攻追擊 → 點燃壓制回復

先用米普普攻降低跑速，再調整角度讓宇宙制約碰到牆或第二名敵人，暈眩命中率更高。

傳送門繞後抓人

3技建立穿牆通道 → 出口米普普攻緩速 → 1技利用牆面暈眩 → 2技放在撤退路線補血 → 必要時閃現調整角度

敵人也能進入傳送門，出口附近先保留一技。神龕放在隊伍撤退側，避免被敵人立刻踩掉。

大絕隔離集火

4技凝滯部分敵人 → 集火未被凝滯的目標 → 1技接凝滯結束點 → 3技追擊或撤退 → 2技補給隊友

大絕目的是製造暫時人數差。不要把隊友正在集火的目標凝滯，應隔離援軍、前排或保護被開的隊友。

GAME PLAN

實戰節奏

前期

宇宙制約命中第一個目標後，若再撞到另一名敵人或牆面就會造成暈眩；利用士兵與牆角找角度，比正面直線施放更穩。守望神龕放在射手後方安全位置，等待充能後再使用。收集調和之音會回復魔力並獲得脫戰跑速，但離線前要確認射手能安全吃線。

中期

巴德的強項是快速改變人數。利用奇幻旅程穿過厚牆，帶著打野繞後或撤退；敵人也能進入同一條通道，因此出口附近要先準備宇宙制約。凝滯命域可讓敵方暫時無法行動，也能保護隊友或物件，施放前要確認隊友理解後續節奏。

後期

大絕最重要的是隔離戰場：可以先凝滯前排集火後排、保住被開的主力，或暫停防禦塔與史詩物件創造時間。不要在隊友爆發已經落下時把敵人變成無敵。米普強化普攻具備緩速與範圍效果，團戰先普攻關鍵目標再接一技，能提高控制命中率。

ADAPTIVE BUILD

依對局調整

輔助調整以團隊承傷、解控與保護主力為優先，不為了單一敵人破壞整套功能裝。

物理傷害多高優先

觸發：敵方主要輸出集中在射手、物理刺客或普攻型英雄。

  • 暴擊射手特別肥敵方主力射手以暴擊普攻為核心，而且已經是團戰主要威脅時。

    蘭頓之兆進一步降低暴擊傷害，適合第二層針對。

魔法傷害多高優先

觸發：敵方主要威脅來自法師、AP刺客或大量範圍魔法傷害。

  • 魔法承傷鞋線敵方主要傷害集中在魔法技能，而且你需要先手承傷時。

    改走水星之靴→鎖鏈軍靴，補魔防、韌性與魔法護盾。

  • 多段魔法輸出敵方法師是持續多段輸出，而不是只有單次爆發時。

    自然之力在連續承受魔法技能後能進一步降低魔法傷害。

控制多最高優先

觸發：敵方硬控能直接抓死己方主力，或你進場後會被連續控制。

  • 韌性鞋線敵方控制密集，且魔法傷害／控制鏈是主要威脅時。

    改走水星之靴→鎖鏈軍靴，直接補韌性與魔防。

提醒：米凱主要替隊友解控；水星彎刀則是物理英雄自我解控，兩者角色不同。

治療／吸血多中優先

觸發：敵方有大量治療、吸血或回復，讓己方集火很難完成擊殺。

  • 重創需求敵方有多名高治療／高吸血英雄，或核心前排能在團戰中大量回血時。

    荊棘之甲讓前排在承受普攻或主動造成傷害時施加重創，同時補物防。

我方主力需要保護高優先

觸發：己方只有一個主要輸出點，且敵方每波團戰都會集中切入他。

  • 團戰保排己方後排需要撐過同一波範圍爆發時。

    日輪的加冕提供即時群體護盾，補上騎士誓願以外的團隊保護。

提醒：保排調整看己方陣容，不是看到敵方刺客就把所有功能裝都換成防裝。
