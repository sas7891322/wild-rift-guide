被動

烈陽之力

傷害性技能會在敵人身上附加烈陽標記；友方英雄造成傷害時可引爆標記，造成額外魔法傷害。雷歐娜自己無法觸發。

1 技

拂曉盾擊

強化下一次普攻，造成額外魔法傷害並暈眩目標。可在太陽聖劍進場後立即接續控制，也能留給貼近主力的敵人。

2 技

日蝕

立即提高物理防禦與魔法防禦，延遲後對附近敵人造成魔法傷害；命中敵人會延長防禦效果。應在進場前預先開啟。

3 技

太陽聖劍

投出日光劍刃，對路徑敵人造成傷害並定身最後命中的敵方英雄，隨後將雷歐娜拉到其身旁。

4 技

日輪聖芒

在指定區域降下太陽能量，中心敵人受到暈眩，外圍敵人受到緩速。適合遠距開團、封路或反開突進。

COMBOS

常用連招

標準日蝕強開

2技提前開啟雙防 → 3技定身並進場 → 普攻接近目標 → 1技暈眩 → 點燃壓制回復

一定先開日蝕再進場，讓雙防覆蓋整段換血。三技拉近後立刻用一技控制，隊友才能連續引爆被動。

大絕中心接控制鏈

4技中心暈眩 → 2技準備扛傷 → 3技追上目標 → 1技續暈 → 普攻協助集火

先用大絕中心固定後排，再接三技與一技延長控制。大絕只命中外圍緩速時，要先評估是否仍值得進場。

閃現盾擊反開

2技開啟雙防 → 閃現貼近突進者 → 1技立即暈眩 → 4技封鎖後續敵人 → 3技追擊或回到戰場

敵方刺客切入時，用閃現一技最快速保住主力，再把大絕放在後續援軍路線。三技可追擊，也可改抓另一名威脅。

GAME PLAN

實戰節奏

前期

一級可先點日蝕穩定換血與扛傷，二級取得太陽聖劍後開始威脅強開。進場前先開日蝕，讓雙防覆蓋突進與對手反擊；太陽聖劍命中後接拂曉盾擊形成連續控制。雷歐娜自身無法引爆烈陽之力，必須確認射手能跟上再進場。

中期

完成輔助任務後跟著打野進入河道，海克斯閃現可從草叢或牆後改變進場角度。日輪聖芒可遠距先手，但中心暈眩比外圍緩速更有價值；若敵方有反開角色，也可以保留大絕等對手進場後反打。每次進場前確認隊友距離、敵方位移與自身撤退路線。

後期

雷歐娜進場後缺乏可靠退出手段，因此不要只因三技命中前排就固定飛入。敵方後排露出時可用大絕中心先控制，再接三技與一技；若己方輸出被刺客威脅，則留一技和大絕保排。日蝕應在承受爆發前提前開啟，而不是掉血後才使用。

ADAPTIVE BUILD

依對局調整

輔助調整以團隊承傷、解控與保護主力為優先，不為了單一敵人破壞整套功能裝。

物理傷害多高優先

觸發：敵方主要輸出集中在射手、物理刺客或普攻型英雄。

  • 暴擊射手特別肥敵方主力射手以暴擊普攻為核心，而且已經是團戰主要威脅時。

    蘭頓之兆進一步降低暴擊傷害，適合第二層針對。

魔法傷害多高優先

觸發：敵方主要威脅來自法師、AP刺客或大量範圍魔法傷害。

  • 魔法承傷鞋線敵方主要傷害集中在魔法技能，而且你需要先手承傷時。

    改走水星之靴→鎖鏈軍靴，補魔防、韌性與魔法護盾。

  • 多段魔法輸出敵方法師是持續多段輸出，而不是只有單次爆發時。

    自然之力在連續承受魔法技能後能進一步降低魔法傷害。

控制多最高優先

觸發：敵方硬控能直接抓死己方主力，或你進場後會被連續控制。

  • 韌性鞋線敵方控制密集，且魔法傷害／控制鏈是主要威脅時。

    改走水星之靴→鎖鏈軍靴，直接補韌性與魔防。

  • 控制鏈承傷你是主要進場點，會連續吃到硬控時。

    堅毅讓被控期間更耐打，適合前排承接第一波技能。

提醒：米凱主要替隊友解控；水星彎刀則是物理英雄自我解控，兩者角色不同。

治療／吸血多中優先

觸發：敵方有大量治療、吸血或回復，讓己方集火很難完成擊殺。

  • 維持標準配置

    標準配置已經有重創，不必重複購買。

我方主力需要保護高優先

觸發：己方只有一個主要輸出點，且敵方每波團戰都會集中切入他。

  • 團戰保排己方後排需要撐過同一波範圍爆發時。

    日輪的加冕提供即時群體護盾，補上騎士誓願以外的團隊保護。

提醒：保排調整看己方陣容，不是看到敵方刺客就把所有功能裝都換成防裝。
