手機版連招與機制

刪除大絕第四發後自動取得低語普攻暴擊跑速的錯誤步驟；架槍結束靠走位或鬼步撤離，並明示第四發連招須先有正確剩餘彈數。

彈跳標記消耗

1技彈跳 → 普攻標記 → 2技定身 → 接續普攻

先用狂舞手雷經殘血士兵彈到英雄，再普攻留下標記並接致命伏筆；二技命中後打一發就撤，避免換彈時被反打。

陷阱控制爆發

3技陷阱緩速 → 2技定身 → 普攻 → 1技補傷害 → 第四發收尾

把魔幻時刻放在狹口或敵方退路，緩速後致命伏筆更容易命中；第四發留到目標低血量時打出最大斬殺收益。 示意最後一發須先安排剩餘彈數；不是任何起始彈匣都能在這個固定步驟打出第四發。

遠距開戰收割

2技接控 → 4技架槍 → 第一至三發減速 → 第四發暴擊

先用二技配合隊友控制，再在敵方無法立即突進的位置開大；前幾發用來減速與逼位，第四發瞄準最低血量目標。 大絕第四發不觸發低語的普攻暴擊跑速；結束後步行或開鬼步調位，安全回到普攻距離後才接暴擊走砍。

實戰節奏

前期

隨時掌握彈匣與換彈節奏，利用第四發和狂舞手雷彈跳建立血量差。第四發打完後會進入換彈空窗，不能在沒有退路時繼續站前；致命伏筆較適合接隊友控制或敵人已被標記時使用。

中期

蒐集者與狂暴利刃成形後，以充能普攻和第四發完成短交換，再用跑速撤出換彈；多明尼克第三件補穿甲。陷阱先保入口，二技接隊友傷害標記，架大前確認刺客位置與退路。

後期

燼不靠高攻速持續站樁，而是依靠每發普攻、技能與跑速加成反覆拉扯。保持在前排後方，第四發優先打能安全命中的低血量目標；若敵方刺客仍未露面，大絕不要過早架槍。

雙人線配合

下列輔助配合以技能互動為依據。拉克絲、枷蘿、納帝魯斯仍可配合本頁打法；先確認對手輔助的控制與兩邊召喚師技能，單一射手對局不代表必勝。

輔助配合

拉克絲

長距離定身能接致命伏筆，雙方可在安全距離完成控制與爆發。

枷蘿

植物消耗與纏繞能限制走位，方便燼接控制、第四發與大絕。

納帝魯斯

穩定先手能讓燼遠距跟上致命伏筆，再完成後續爆發。

依陣容調整配置

依燼的四發彈匣點射與遠距收尾路線選擇替換；先看實際死亡與傷害不足原因。

高生命／高防禦前排

依敵方前排成形調整

觸發：敵方前排已形成高生命或高防禦，正面輸出受阻。

換裝原則

燼保留前述五成裝加獨立鞋線；同一格不同情境擇一替換，不全部加購。

先保留預設穿甲核心，單一裝備格的調整不代表重買另一套。

刺客／瞬間爆發

保命格可提早

觸發：被同一輪突進秒殺，無法打出主要技能與普攻。

被物理集火時保留復活機會

嗜血者 → 守護天使

主要死亡原因是刺客或突進一次切入，且隊友能掩護復活位置。

嗜血者整格換守護天使，犧牲部分四發彈匣點射與遠距收尾或持續防禦；復活後無人接應時先改善站位。

魔法爆發改魔提斯

嗜血者 → 魔提斯深淵

敵方主要擊殺來源是魔法爆發，且尚未裝另一件生命線裝備。

以嗜血者換魔提斯處理魔法爆發；不把魔防誤當通用抗物理方案。

強開線改骨甲

迅捷 → 骨甲

選角時已確定會承受短時間連段強開。

放棄迅捷的進攻收益，先保住燼的第一輪輸出。

復活與魔法生命線處理的傷害不同，按實際威脅擇一；盾弓與魔提斯不重複保留。

控制鏈

先判斷控制能否解除

觸發：可解除的禁錮、暈眩等控制反覆中斷輸出。

關鍵控制用主動解控

嗜血者 → 水星彎刀

可解除的控制反覆讓自己無法輸出，且閃現不能解決。

以嗜血者換水星彎刀；主動要手動使用，不能解除擊飛或擊退，也不是舊版附魔。

水星彎刀是成裝，不佔鞋子升級；擊飛、擊退須靠預先走位或隊友保護。

治療／吸血

治療已影響集火時

觸發：敵方持續治療抵銷集火，且團隊缺乏穩定重創。

重創取代最大化穿甲收益

多明尼克的問候 → 致死宣告

敵方治療或吸血持續影響勝負，隊友無法穩定施加重創。

致死宣告替換多明尼克；保留暴擊、穿甲與重創，不並排買兩件。

需要時先用死刑宣告過渡；不要把所有敵方英雄都當成必出重創的理由。

反覆大型護盾

團隊無其他反盾者才承擔

觸發：大量反覆護盾持續阻止集火，且自己能穩定命中目標。

必要時補巨蛇鋒牙

嗜血者 → 巨蛇鋒牙

隊友無法施加反盾，且護盾確實抵銷主要輸出。

嗜血者換巨蛇鋒牙會犧牲原末段功能；燼仍需保留主要輸出核心，只有單一小護盾時不換。

反盾屬團隊分工，不為一個小盾放棄整條普攻或技能路線。

需要一次遠距點射｜整套情境配置
