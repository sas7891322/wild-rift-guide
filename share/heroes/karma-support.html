真言強化遠距消耗鎖鏈定身群體護盾

被動

真言符印

施放三次技能後，下一個基礎技能會獲得真言強化，提升傷害、控制或護盾效果。

1 技

輪迴怒火

射出靈能彈，命中後造成範圍魔法傷害與緩速；真言強化後會形成延遲二段爆炸。

2 技

特化鏈結

連結敵方英雄造成傷害並揭露位置，連線未被拉斷會再次傷害與定身；真言強化可連結額外目標並延長控制。

3 技

靈能啟示

為友軍提供護盾與跑速；真言強化後把護盾與加速擴散至附近友軍。

4 技

飛昇擁抱

在指定區域造成魔法傷害並形成靈能環，短暫延遲後把仍在環內的敵人拉向中心。

COMBOS

常用連招

真言一技消耗

強化1技命中 → 利用緩速調整位置 → 普攻補傷害 → 3技護盾撤退

確定被動強化已準備完成後再施放一技，二段爆炸需要敵人仍停留在範圍內。

鎖鏈定身追擊

2技建立鎖鏈 → 3技加速跟住目標 → 1技緩速限制逃跑 → 鎖鏈完成定身 → 虛弱敵方主力

三技跑速用來保持連線，一技放在敵人退路。真言強化二技可同時限制更多目標。

大絕拉回群盾反開

4技放在進場敵人腳下 → 1技範圍緩速 → 強化3技群體護盾加速 → 2技鎖住主要威脅 → 帶隊拉開或反追

大絕把敵人拉回中心後，強化三技同時保護多人並調整隊伍站位。

GAME PLAN

實戰節奏

前期

利用輪迴怒火的範圍傷害與緩速同步消耗敵人，但不要過度推線讓自己失去安全距離。持續追蹤真言符印計數：需要壓血時把強化留給一技，遭遇強開或準備追擊時則保留給靈能啟示，提供附近隊友護盾與跑速。特化鏈結連上後用三技加速跟住目標，避免鎖鏈被拉斷。

中期

卡瑪擅長帶隊快速搶河道位置。群體護盾與加速可讓隊伍先進入物件區或迅速撤退；大絕飛昇擁抱在窄口能把敵人拉向中心，接強化一技打出範圍爆發。做視野時不要單獨走進黑暗，先用一技探草並保持三技能隨時自保。

後期

團戰站在隊伍中央，根據威脅分配真言：敵人尚未進場時可用強化一技消耗，刺客或坦克衝入時優先強化三技保護多人。大絕適合反開、打斷敵方陣型或把分散目標拉回火力中心；二技則留給需要長時間限制的突進者。

ADAPTIVE BUILD

依對局調整

輔助調整以團隊承傷、解控與保護主力為優先，不為了單一敵人破壞整套功能裝。

物理傷害多高優先

觸發：敵方主要輸出集中在射手、物理刺客或普攻型英雄。

  • 團隊物理爆發保護敵方物理爆發能同時壓低多名隊友血量時。

    日輪的加冕提供團隊護盾與雙防，讓軟輔先保住主力再繼續施放治療／護盾。

魔法傷害多高優先

觸發：敵方主要威脅來自法師、AP刺客或大量範圍魔法傷害。

  • 團隊魔法爆發保護敵方魔法爆發會同時威脅多名隊友時。

    日輪的加冕提供團隊護盾與雙防，能先撐過第一輪範圍爆發。

控制多最高優先

觸發：敵方硬控能直接抓死己方主力，或你進場後會被連續控制。

  • 維持標準配置

    標準配置已有米凱、韌性鞋線或其他解控／防先手工具。

提醒：米凱主要替隊友解控；水星彎刀則是物理英雄自我解控，兩者角色不同。

治療／吸血多中優先

觸發：敵方有大量治療、吸血或回復，讓己方集火很難完成擊殺。

  • 重創需求敵方有多名高治療／高吸血英雄，或核心前排能在團戰中大量回血時。

    黑魔禁書能由魔法傷害穩定施加重創，適合法師與軟輔處理大量治療。

我方主力需要保護高優先

觸發：己方只有一個主要輸出點，且敵方每波團戰都會集中切入他。

  • 主力被集火己方主力每波都會被強開，而且單靠技能護盾仍撐不過第一輪時。

    日輪的加冕提供額外即時護盾，讓你有時間接後續治療與保排技能。

提醒：保排調整看己方陣容，不是看到敵方刺客就把所有功能裝都換成防裝。
