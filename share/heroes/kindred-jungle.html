被動

鏡爪印記

標記敵方英雄與野怪進行獵殺；成功取得印記會永久強化基礎技能，達到特定層數時提高普攻距離。

1 技

舞動箭矢

神羊朝指定方向跳躍並射擊附近敵人；位於魔狼狂熱區域內時，冷卻時間會大幅縮短。

2 技

魔狼狂熱

召喚魔狼在區域內攻擊敵人；神羊移動與普攻會累積治療能量，滿層後下一次普攻回復生命。

3 技

恐懼蔓延

緩速並標記目標；對該目標完成第三次普攻時，魔狼會撲擊並依目標已損生命造成額外傷害。

4 技

神羊喘息

創造一個無法被擊殺的領域，範圍內所有單位生命降至門檻後不會繼續下降；領域結束時所有單位獲得治療。

COMBOS

常用連招

基礎遠程 Gank

3技緩速標記 → 2技區域 → 1技位移 → 普攻 → 第三擊觸發

先用三技減速並建立三次普攻斬殺條件，再在二技區域內用一技反覆拉扯。

翻牆追擊

1技翻牆 → 2技 → 3技 → 普攻 → 1技再調位

一技可穿越薄牆建立出其不意的角度；二技先放好後，一技冷卻更短，能持續保持射程。

神羊喘息反打

4技保命 → 2技 → 3技標記 → 普攻 → 1技拉開 → 領域結束後收割

大絕期間先壓低敵人並疊好三技，領域結束後用一技拉開，再完成第三擊；注意大絕也會保護敵方。

GAME PLAN

實戰節奏

前期

先以穩定清野和河道資訊為主，不要為第一個野怪印記盲目入侵。二技區域內反覆用一技拉扯，三技用於收尾或阻止敵人逃跑；英雄印記要選擇真正可能接戰的路線。

中期

累積印記提高射程後，物件團能在安全距離持續輸出。利用一技穿越薄牆建立視野差，抓落單後再轉物件；大絕保留處理爆發、重擊博弈或救核心隊友。

後期

站在前排之後持續輸出，不為追擊跨過安全線。大絕結束前先壓低敵人並疊好三技，領域消失後立刻拉開並完成第三擊收割。

ADAPTIVE BUILD

依對局調整

打野先維持標準刷野與節奏裝，只有敵方陣容或我方前排需求明顯時才調整。

坦克多高優先

觸發：敵方前排多，物件團與正面團戰會長時間卡在高生命目標上。

  • 維持標準配置

    標準配置已經具備足夠打坦能力，維持核心即可。

刺客／爆發多高優先

觸發：敵方能在你進場或搶物件前快速把你秒掉。

  • 物理爆發威脅敵方物理刺客／戰士能直接切到你，而且你常在第二輪輸出前死亡時。

    守護天使提供物防與復活，適合把最後一個純輸出位換成容錯。

  • 魔法爆發威脅敵方法師／AP刺客的單次爆發才是主要死亡來源時。

    魔提斯深淵提供魔防與低血量魔法護盾，比單純增加輸出更能保住進場或持續輸出。

  • 爆發對局符文對面主要靠短時間連段把你秒掉，而且目前標準符文沒有骨甲時。

    骨甲直接降低同一名敵人接續幾次技能或普攻的傷害。

控制多高優先

觸發：進場或搶物件時經常被控制鏈直接中斷節奏。

  • 關鍵硬控解法敵方有 1～2 個關鍵硬控，只要命中就可能直接死亡時，將後期彈性位改成水星彎刀。

    先購買水銀飾帶取得主動解控，之後再合成水星彎刀；水銀飾帶是合成組件，不是另一件要與水星彎刀互換的成裝。

  • 重控制陣容控制來源很多，不是只靠一次主動解控就能解決時。

    犧牲部分輸出型傳奇符文，換取韌性與緩速抗性。

治療／吸血多中優先

觸發：敵方前排、鬥士或吸血核心能在物件團長時間回復。

  • 維持標準配置

    標準配置已經有重創，維持即可。

我方缺前排中優先

觸發：我方陣容沒有可靠第一承傷點，團戰需要有人更早進場吸收注意力。

  • 提高進場容錯我方沒有前排、你必須更早進場吸收注意力時。

    守護天使不是把你變成坦克，而是提高進場後的容錯，避免第一波直接蒸發。

提醒：「缺前排」不代表所有打野都要改坦裝；刺客、法師與射手打野硬轉坦通常會失去英雄價值。
