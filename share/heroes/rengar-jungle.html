被動

潛行怒獅

在草叢或偽裝狀態下，下一次普攻可跳向目標。施放基礎技能累積殘虐值，滿層後強化下一個基礎技能；不同英雄的擊殺或助攻會提高物攻。

1 技

兇殘打擊

強化接下來的普攻並提高攻速，第一下造成額外物理傷害且視為暴擊。強化版本提供更高攻速與額外傷害，是主要爆發與清野技能。

2 技

怒獅戰吼

對周圍敵人造成魔法傷害，並回復近期承受傷害的一部分。強化版本還能移除自身控制，是雷葛爾反打與保命關鍵。

3 技

狩獵拋繩

投擲繩索造成物理傷害與緩速，並揭露命中區域。強化版本會定身目標；跳躍途中也能施放。

4 技

血性獵殺

提高跑速、揭露最近的敵方英雄並進入偽裝，期間可從遠處跳向目標；首次跳擊會降低目標物防。

手機版連招與機制

草叢跳躍與殘虐值決定強化技能，奪魄暴擊路線需要確認強化 Q 是否真的可用。補上雙 Q 所需殘虐條件，避免少一個技能仍直接強化。

草叢四層爆發

草叢跳擊 → 空中3技 → 2技補殘虐 → 1技重置 → 2技 → 強化1技

從草叢起跳並在空中丟三技，落地後快速打完三個基礎技能，滿殘虐再用強化一技完成爆發。 強化一技前確認殘虐已滿；未滿時不成立，不能無條件連用兩次一技。

大絕抓單

4技偽裝 → 跳擊降防 → 空中3技 → 2技補殘虐 → 1技 → 強化1技

大絕接近時先判斷目標是否有控制；若風險高，可把滿層殘虐留給強化二技解控。 強化一技前確認殘虐已滿；未滿時不成立，不能無條件連用兩次一技。

強化定身留人

草叢跳擊 → 1技 → 2技 → 3技 → 強化3技定身

需要配合隊友而非單殺時，將強化技能留給三技，定身能讓後續控制與傷害更穩定。

實戰節奏

前期

利用草叢跳躍縮短清野移動並快速累積殘虐值。第一輪清野後可在河道草叢主動找單挑，但要先規劃好強化技能：需要爆發用強化一技，需要解控或回血則保留強化二技。

中期

奪魄之鐮 → 蒐集者 → 無盡之刃為預設前段順序。草叢跳躍與殘虐值決定強化技能，奪魄暴擊路線需要確認強化 Q 是否真的可用。後兩格依敵方實際威脅替換；先完成關鍵核心，再決定防裝與穿透，支援物件前確認重擊充能及隊友線權。

後期

正面五對五容易被控制與保排化解，應先清理視野、從側翼或草叢等待。若無法秒殺核心，就用強化三技定身或強化二技解控後撤，不要把所有技能一次交空。

對局與隊伍配合

以同頁打野威脅名單嘉文四世、拉姆斯、赫克林更新，有利名單僅是既有機制判斷，排除與威脅重複者；雷葛爾入侵仍看兩側線權、血量及關鍵技能，不當作固定單挑勝率。
