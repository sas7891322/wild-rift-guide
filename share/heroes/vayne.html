被動

夜之狩獵

朝鄰近敵方英雄移動時提高跑速，讓汎更容易追擊與收割。

1 技

翻滾瞄準

向指定方向翻滾並強化下一次普攻；大絕期間施放可短暫進入隱形。

2 技

神聖銀箭

連續三次攻擊或技能命中同一目標時，造成依目標最大生命計算的真實傷害；主動使用可提高攻速並回復部分造成的傷害。

3 技

重型弩箭

以重弩擊退目標並造成物理傷害；若目標撞上牆體，會受到額外傷害並被暈眩。

大絕

死亡通緝

暫時提高物攻並強化夜之狩獵與翻滾瞄準，使汎獲得更強的追擊、隱身與拉扯能力。

COMBOS

常用連招

三環短換血

普攻第一層 → 1技翻滾強化 → 普攻第二層 → 普攻觸發三環

先普攻後用翻滾瞄準重置站位與強化下一擊，再補第三下觸發神聖銀箭。敵方準備反打時不要勉強追第三層。

釘牆爆發

3技釘牆 → 4技強化 → 1技翻滾 → 強化普攻 → 持續追擊 → 三環真傷

確認重型弩箭能撞牆再出手，控制時間內開大並快速疊滿三環；若角度不穩，三技應保留用來擊退突進者。

大絕隱身拉扯

4技死亡通緝 → 1技隱身調位 → 普攻輸出 → 再次翻滾 → 持續風箏 → 3技擊退自保

大絕期間翻滾可短暫隱身，利用失去視野的瞬間改變走位方向；三技留到敵方突進貼近或能穩定釘牆時再使用。

GAME PLAN

實戰節奏

前期

汎射程短、推線慢，前期以補刀與血量管理優先。不要為了硬打神聖銀箭三環走進敵方雙人組的完整技能範圍；等對手交掉關鍵消耗或控制後，再用翻滾瞄準調整角度打一輪短換血。重型弩箭通常留給反突進，只有能穩定釘牆時才主動出手。

中期

磁性雷射槍與鬼索的狂暴之刃成形後，三環觸發速度與追擊能力明顯提升。優先跟隊打小規模戰，利用側邊牆體尋找重型弩箭角度；沒有視野時不要獨自深入邊線，汎雖然單挑強，但仍怕先手控制。

後期

開啟死亡通緝後，以翻滾隱形躲避關鍵技能並持續風箏，優先攻擊最近且安全的目標。神聖銀箭真實傷害能處理高生命前排，不需要冒險繞過坦克強切後排；每次翻滾都要同時考慮下一個安全位置。

ADAPTIVE BUILD

依對局調整

先照標準出裝與符文走；只有敵方陣容真的形成威脅時，再替換必要格子。

坦克多高優先

觸發：敵方至少有 2 名高生命／高護甲前排，而且團戰多數時間必須先處理前排。

  • 維持標準配置

    標準配置已經有足夠打坦能力；如果已有斷切、百分比穿透或殞落，就不要為了「坦克多」硬拆暴擊／攻速核心。

刺客／爆發多高優先

觸發：敵方有多名能直接貼到後排的刺客／爆發英雄，或你常在開始輸出前就被秒。

  • 魔法爆發威脅敵方法師／AP刺客的單次爆發才是主要死亡來源時。

    魔提斯深淵提供魔防與低血量魔法護盾，比單純增加輸出更能保住進場或持續輸出。

控制多最高優先

觸發：敵方有多個硬控，而且控制鏈會讓你直接失去輸出時間。

  • 關鍵硬控解法敵方有 1～2 個關鍵硬控，只要命中就可能直接死亡時，將後期彈性位改成水星彎刀。

    先購買水銀飾帶取得主動解控，之後再合成水星彎刀；水銀飾帶是合成組件，不是另一件要與水星彎刀互換的成裝。

  • 重控制陣容控制來源很多，不是只靠一次主動解控就能解決時。

    犧牲部分輸出型傳奇符文，換取韌性與緩速抗性。

提醒：水星彎刀的路線是先購買水銀飾帶，再完成水星彎刀；水銀飾帶不是另一件終局成裝。

治療／吸血多中優先

觸發：敵方有多名高治療／高吸血英雄，或核心前排能在團戰中大量回血。

  • 重創需求敵方有多名高治療／高吸血英雄，或核心前排能在團戰中大量回血時。

    致死宣告兼顧暴擊、穿透與重創，適合射手在不拆核心輸出邏輯下補反治療。

護盾多低～中優先

觸發：敵方有多個大量護盾來源，而且己方沒有其他更適合負責反護盾的英雄。

  • 大量護盾處理敵方有多個大量護盾來源，而且隊伍目前缺乏穩定反護盾手段時。

    巨蛇鋒牙降低敵方護盾，只有護盾真的成為團戰主要問題時才值得犧牲一般輸出位。

提醒：反護盾裝通常是彈性位，不要只因敵方有一個小護盾就固定購買。
