手機版連招與機制

被動改普攻或技能傷害英雄觸發；二技是限時攻速與彈射，三技成功格擋回復生命並觸發被動跑速，非回魔。士氣屬大絕機制，連招不再標作被動。

雙段飛刃消耗

1技第一段命中 → 普攻觸發加速 → 1技回程命中 → 2技強化普攻 → 彈射追擊

調整走位讓迴旋之刃的去程與回程都命中，普攻取得被動跑速後再接二技追擊；敵方準備反打時立即拉開。

護盾反打

3技格擋關鍵技能 → 普攻加速 → 2技彈射 → 強化普攻 → 1技追擊

法術護盾成功擋下控制或爆發後，利用對方技能空窗反打；不要預判過早，否則敵人可等待護盾結束再出手。

狩獵團隊推進

4技全隊加速 → 2技範圍普攻 → 持續彈射 → 1技穿越多人 → 大絕期間累積士氣 → 滿層自動刷新持續時間

大絕開啟後持續攻擊累積士氣，利用更短技能冷卻反覆輸出；刷新大絕後依戰況決定繼續追擊或帶全隊撤退。 後兩格表示大絕的自動狀態變化，不是額外重按大絕或被動的士氣。

實戰節奏

前期

迴旋之刃與十字彈射能快速處理兵線，但過度使用技能會推線並消耗魔力。法術護盾要保留阻擋最關鍵的控制或爆發，不要拿來擋普通消耗；成功格擋後利用生命回復與跑速差反打。

中期

雲陶狂箭與無盡成形後，先清兵再跟隊轉線，多明尼克補前排穿甲，那歐第四件延長基本技能循環。法術盾成功擋招可回復生命並取得跑速，光盾則留給技能盾擋不完的後續爆發。

後期

正面團戰站在安全位置攻擊前排，利用十字彈射把傷害擴散到後排。狩獵期間技能冷卻更快，持續造成傷害累積士氣，滿層後把強化效果轉給隊友並刷新大絕；護盾仍要保留處理決定生死的技能。

對局與隊伍配合

尤娜拉、圖奇擅長持續普攻，不能只靠一次法術盾擋住整段輸出；路西恩短爆發時要避免站在穿兵一技路徑，清線後跟輔助退到安全距離。 威脅名單採同分路指南，較有利名單保留機制判斷並移除與威脅名單重疊者；現有輔助組合逐項複核技能互動後保留。

下列輔助配合以技能互動為依據。卡瑪、悠咪、索娜仍可配合本頁打法；先確認對手輔助的控制與兩邊召喚師技能，單一射手對局不代表必勝。

輔助配合

卡瑪

悠咪

附身增益與希維爾大絕疊加後機動性很高，適合團隊追擊與拉扯。

索娜

雙範圍增益能強化中後期團戰，希維爾也能替索娜提供穩定前排輸出節奏。

依陣容調整配置

依希維爾的彈射普攻及雙段飛刃路線選擇替換；先看實際死亡與傷害不足原因。

高生命／高防禦前排

依敵方前排成形調整

觸發：敵方前排已形成高生命或高防禦，正面輸出受阻。

換裝原則

希維爾保留前述五成裝加獨立鞋線；同一格不同情境擇一替換，不全部加購。

先保留預設穿甲核心，單一裝備格的調整不代表重買另一套。

刺客／瞬間爆發

保命格可提早

觸發：被同一輪突進秒殺，無法打出主要技能與普攻。

被物理集火時保留復活機會

嗜血者 → 守護天使

主要死亡原因是刺客或突進一次切入，且隊友能掩護復活位置。

嗜血者整格換守護天使，犧牲部分彈射普攻及雙段飛刃或持續防禦；復活後無人接應時先改善站位。

魔法爆發改魔提斯

嗜血者 → 魔提斯深淵

敵方主要擊殺來源是魔法爆發，且尚未裝另一件生命線裝備。

以嗜血者換魔提斯處理魔法爆發；不把魔防誤當通用抗物理方案。

復活與魔法生命線處理的傷害不同，按實際威脅擇一；盾弓與魔提斯不重複保留。

控制鏈

先判斷控制能否解除

觸發：可解除的禁錮、暈眩等控制反覆中斷輸出。

關鍵控制用主動解控

嗜血者 → 水星彎刀

可解除的控制反覆讓自己無法輸出，且閃現不能解決。

以嗜血者換水星彎刀；主動要手動使用，不能解除擊飛或擊退，也不是舊版附魔。

水星彎刀是成裝，不佔鞋子升級；擊飛、擊退須靠預先走位或隊友保護。

治療／吸血

治療已影響集火時

觸發：敵方持續治療抵銷集火，且團隊缺乏穩定重創。

重創取代最大化穿甲收益

多明尼克的問候 → 致死宣告

敵方治療或吸血持續影響勝負，隊友無法穩定施加重創。

致死宣告替換多明尼克；保留暴擊、穿甲與重創，不並排買兩件。

需要時先用死刑宣告過渡；不要把所有敵方英雄都當成必出重創的理由。

反覆大型護盾

團隊無其他反盾者才承擔

觸發：大量反覆護盾持續阻止集火，且自己能穩定命中目標。

必要時補巨蛇鋒牙

嗜血者 → 巨蛇鋒牙

隊友無法施加反盾，且護盾確實抵銷主要輸出。

嗜血者換巨蛇鋒牙會犧牲原末段功能；希維爾仍需保留主要輸出核心，只有單一小護盾時不換。

反盾屬團隊分工，不為一個小盾放棄整條普攻或技能路線。
