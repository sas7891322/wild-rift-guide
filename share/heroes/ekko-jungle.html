被動

共振驅動-Z

對同一目標的第三次普攻或傷害技能會造成額外魔法傷害；命中英雄時同時獲得跑速，方便換血後拉開。 7.2b 傷害魔攻係數提高至 80%。

1 技

時光樞紐

投擲時光裝置造成傷害，命中英雄或到達最遠距離後展開緩速區域，隨後返回並再次造成傷害。

2 技

時空攔截

被動讓普攻對低生命目標造成額外傷害；主動在延遲後生成區域，艾克進入時獲得護盾並暈眩範圍內敵人。 7.2b 對低生命目標的已損失生命係數提高至 3% + 0.025%魔攻。

3 技

相位轉移

先向指定方向衝刺，接下來的普攻增加距離並瞬移至目標造成額外魔法傷害。

4 技

計時開始

艾克短暫無法被指定並回到數秒前的位置，回復生命並對抵達位置周圍敵人造成高額魔法傷害。

COMBOS

常用連招

預判暈眩 Gank

2技預放 → 3技衝刺 → 強化普攻瞬移 → 1技 → 三環觸發

二技從敵方視野外施放，利用三技與強化普攻瞬間進入區域，觸發暈眩後接一技與普攻完成三環。

短距爆發撤離

3技 → 強化普攻 → 1技 → 三環 → 4技回溯

快速打出三環取得跑速後撤，遭到集火時用大絕回到進場前位置，並可嘗試讓殘影命中目標。

大絕反打

2技封鎖 → 3技進場 → 1技 → 4技回到殘影 → 普攻收尾

先讓敵人追進大絕殘影附近，再回溯造成爆發並回復生命，適合誘敵深入與物件坑反打。

GAME PLAN

實戰節奏

前期

前期單挑不算穩定，先用一技與被動三環完成高效率清野。Gank 前從視野外預放二技，讓落點覆蓋敵人退路，再用三技進入範圍觸發暈眩與護盾。

中期

完成核心裝後可從側翼尋找後排，用三技接普攻瞬移貼近並快速觸發被動加速。注意大絕殘影的位置，確保進場後能回到安全區或命中多人。7.2b 三環與殘血斬殺增強，側翼命中二技後更容易完成第一輪收割。

後期

團戰重點不是持續站樁，而是打出一輪爆發後撤離。二技可先封鎖戰場，大絕既能回血保命，也能配合殘影造成高額範圍傷害。

ADAPTIVE BUILD

依對局調整

打野先維持標準刷野與節奏裝，只有敵方陣容或我方前排需求明顯時才調整。

坦克多高優先

觸發：敵方前排多，物件團與正面團戰會長時間卡在高生命目標上。

  • 前排處理敵方至少有 2 名高生命／高抗性前排，而且團戰多數時間必須先打前排時。

    用百分比生命灼燒或魔法穿透提高長時間處理高血量／高魔防前排的效率。

刺客／爆發多高優先

觸發：敵方能在你進場或搶物件前快速把你秒掉。

  • 爆發對局符文對線或團戰經常被同一名刺客短時間連段時。

    骨甲降低接續傷害，適合換掉較貪輸出的副系符文。

控制多高優先

觸發：進場或搶物件時經常被控制鏈直接中斷節奏。

  • 控制鏈生存控制來源密集、被控後容易直接接第二段傷害時。

    堅毅提供韌性，受到硬控時也能短暫提高雙防。

治療／吸血多中優先

觸發：敵方前排、鬥士或吸血核心能在物件團長時間回復。

  • 重創需求敵方有多名高治療／高吸血英雄，或核心前排能在團戰中大量回血時。

    黑魔禁書能由魔法傷害穩定施加重創，適合法師與軟輔處理大量治療。

我方缺前排中優先

觸發：我方陣容沒有可靠第一承傷點，團戰需要有人更早進場吸收注意力。

  • 維持標準配置

    這隻英雄不適合為了「缺前排」硬改成主坦；維持自己的輸出／功能，讓巴龍路或輔助補前排更合理。

提醒：「缺前排」不代表所有打野都要改坦裝；刺客、法師與射手打野硬轉坦通常會失去英雄價值。
