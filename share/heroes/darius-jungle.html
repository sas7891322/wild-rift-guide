被動

絞喉

普攻與傷害技能使敵人流血；疊滿後達瑞斯獲得高額物攻並能快速把其他英雄疊滿。

1 技

毀滅風暴

揮斧一圈，外圈斧刃造成更高傷害、治療自身並附加流血。

2 技

殘廢打擊

強化下一次普攻造成額外物理傷害並大幅緩速。

3 技

索魂奪命

被動獲得物理穿透；主動用斧柄把前方敵人拉到身前並減速。

4 技

諾克薩斯斷頭台

跳向英雄造成真實傷害，流血層數會提高傷害；擊殺可重置並短暫免消耗再次施放。

手機版連招與機制

外圈 Q 回復與疊滿流血後的斬殺才是交戰條件，相位與移速幫助接近而非空追。修正零起始層五層連招，補足第五次傷害來源；E拉回不疊流血。

河道 Gank 拉回

3技拉回 → 普攻 → 2技重置緩速 → 1技外圈

拉回後用普攻接二技重置，再走位讓一技外圈命中，兼顧疊血怒與回復。

五層斬殺

3技 → 普攻 → 2技 → 1技外圈 → 普攻 → 再普攻補滿第五層 → 4技

從零層開始，三技不造成流血；普攻、二技強化普攻、一技外圈及後續兩次普攻補滿五層。先確認層數與斬殺線再開大，避免少一層卻預期滿層傷害。

物件團連續斷頭

1技外圈 → 3技拉多人 → 2技 → 普攻 → 4技收割

先鎖定低血量目標完成第一個斬殺，再利用滿層被動轉火；不要為追擊離開重擊範圍。

實戰節奏

前期

一技外圈命中野怪能兼顧傷害與回復，二技重置普攻加快單體清野。Gank 依賴走近後三技拉回，優先支援有控制或敵方缺位移的路線。

中期

三相之力 → 史特拉克手套 → 死亡之舞為預設前段順序。外圈 Q 回復與疊滿流血後的斬殺才是交戰條件，相位與移速幫助接近而非空追。後兩格依敵方實際威脅替換；先完成關鍵核心，再決定防裝與穿透，支援物件前確認重擊充能及隊友線權。

後期

缺乏直接位移，應從側翼或跟隨隊友控制進場。大絕只在能斬殺時施放，成功刷新後才有連續收割價值；同時保留重擊處理關鍵物件。

對局與隊伍配合

以同頁打野威脅名單艾克、拉姆斯、菲艾更新，有利名單僅是既有機制判斷，排除與威脅重複者；達瑞斯入侵仍看兩側線權、血量及關鍵技能，不當作固定單挑勝率。
