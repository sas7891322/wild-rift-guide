絞喉

普攻與傷害技能使敵人流血；疊滿後達瑞斯獲得高額物攻並能快速把其他英雄疊滿。

毀滅風暴

揮斧一圈，外圈斧刃造成更高傷害、治療自身並附加流血。

2 技

殘廢打擊

強化下一次普攻造成額外物理傷害並大幅緩速。

3 技

索魂奪命

被動獲得物理穿透；主動用斧柄把前方敵人拉到身前並減速。

4 技

諾克薩斯斷頭台

跳向英雄造成真實傷害，流血層數會提高傷害；擊殺可重置並短暫免消耗再次施放。

COMBOS

常用連招

河道 Gank 拉回

3技拉回 → 普攻 → 2技重置緩速 → 1技外圈

拉回後用普攻接二技重置，再走位讓一技外圈命中，兼顧疊血怒與回復。

五層斬殺

3技 → 普攻 → 2技 → 1技外圈 → 普攻 → 4技

穿插普攻快速疊滿流血，確認大絕能斬殺後再施放，取得刷新與滿層被動。

物件團連續斷頭

1技外圈 → 3技拉多人 → 2技 → 普攻 → 4技收割

先鎖定低血量目標完成第一個斬殺，再利用滿層被動轉火；不要為追擊離開重擊範圍。

GAME PLAN

實戰節奏

前期

一技外圈命中野怪能兼顧傷害與回復，二技重置普攻加快單體清野。Gank 依賴走近後三技拉回，優先支援有控制或敵方缺位移的路線。

中期

小規模河道戰是主要強勢期。先處理容易疊滿流血的前排或落單目標，取得諾克薩斯之力後再轉火；物件旁要留意不要被遠程陣容持續風箏。

後期

缺乏直接位移，應從側翼或跟隨隊友控制進場。大絕只在能斬殺時施放，成功刷新後才有連續收割價值；同時保留重擊處理關鍵物件。

ADAPTIVE BUILD

依對局調整

打野先維持標準刷野與節奏裝，只有敵方陣容或我方前排需求明顯時才調整。

坦克多高優先

觸發：敵方前排多，物件團與正面團戰會長時間卡在高生命目標上。

  • 高生命目標敵方前排生命明顯高於你，而標準符文沒有斷切時。

    斷切能直接提高對高生命敵人的普攻傷害。

刺客／爆發多高優先

觸發：敵方能在你進場或搶物件前快速把你秒掉。

  • 魔法爆發威脅敵方法師／AP刺客的單次爆發才是主要死亡來源時。

    魔提斯深淵提供魔防與低血量魔法護盾，比單純增加輸出更能保住進場或持續輸出。

  • 爆發對局符文對面主要靠短時間連段把你秒掉，而且目前標準符文沒有骨甲時。

    骨甲直接降低同一名敵人接續幾次技能或普攻的傷害。

控制多高優先

觸發：進場或搶物件時經常被控制鏈直接中斷節奏。

  • 關鍵硬控解法敵方有 1～2 個關鍵硬控，只要命中就可能直接死亡時，將後期彈性位改成水星彎刀。

    先購買水銀飾帶取得主動解控，之後再合成水星彎刀；水銀飾帶是合成組件，不是另一件要與水星彎刀互換的成裝。

  • 重控制陣容控制來源很多，不是只靠一次主動解控就能解決時。

    犧牲部分輸出型傳奇符文，換取韌性與緩速抗性。

治療／吸血多中優先

觸發：敵方前排、鬥士或吸血核心能在物件團長時間回復。

  • 重創需求敵方有多名高治療／高吸血英雄，或核心前排能在團戰中大量回血時。

    生化龐克鏈鋸之劍提供物攻、生命與技能加速，適合近戰物理角色補重創。

我方缺前排中優先

觸發：我方陣容沒有可靠第一承傷點，團戰需要有人更早進場吸收注意力。

  • 維持標準配置

    若標準配置已經有半坦容錯，就不必再犧牲核心傷害。

提醒：「缺前排」不代表所有打野都要改坦裝；刺客、法師與射手打野硬轉坦通常會失去英雄價值。
