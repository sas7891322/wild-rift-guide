被動

冥使劍姿

週期性強化普攻，造成額外物理傷害並依目標最大生命回復自身。

1 技

冥血邪劍

三段斬擊各有甜蜜點；命中外圈可造成更高傷害並擊飛，是主要輸出與控場。

2 技

冥府血鏈

揮出鎖鏈傷害並減速目標；敵人未及時離開區域會被拉回中心。

3 技

冥影衝鋒

短距位移並提供續航，可在揮劍途中調整一技能甜蜜點位置。

4 技

劍魔滅世

進入惡魔形態，提升跑速、傷害與治療效果；參與擊殺可延長持續時間。

COMBOS

常用連招

對線短換血

1技外圈 → 3技調位 → 2技 → 二段外圈 → 三段中心

先用一技甜蜜點消耗，再以三技修正第二、三段落點；二技命中後更容易讓後續擊飛完整命中。

開大持續追擊

4技 → 3技 → 一段外圈 → 2技 → 二段外圈 → 三段中心

大絕開啟後利用跑速與三技貼近，連續命中甜蜜點維持回血與控制。

側翼團戰進場

2技 → 一段外圈 → 3技調位 → 二段外圈 → 普攻 → 三段中心

從側面先以二技限制走位，再用三段一技切割後排，不要正面吃完第一輪控制。

GAME PLAN

實戰節奏

前期

用三段一技的甜蜜點同時提高清野速度與續航，三技可在施放一技時修正位置。第一輪後優先支援狹窄河道與有控制的路線，二技命中後更容易接完整三段擊飛。

中期

兩件裝後圍繞預示者與飛龍主動打小規模戰。大絕提供跑速與治療增幅，應在正式接戰前開啟，從側翼連續命中甜蜜點切割陣型。

後期

避免正面吃滿第一輪硬控；等待隊友開戰後第二時間進場。只要一技外圈持續命中，就能靠回血與擊飛拖長團戰。

ADAPTIVE BUILD

依對局調整

打野先維持標準刷野與節奏裝，只有敵方陣容或我方前排需求明顯時才調整。

坦克多高優先

觸發：敵方前排多，物件團與正面團戰會長時間卡在高生命目標上。

  • 高生命目標敵方前排生命明顯高於你，而標準符文沒有斷切時。

    斷切能直接提高對高生命敵人的普攻傷害。

刺客／爆發多高優先

觸發：敵方能在你進場或搶物件前快速把你秒掉。

  • 魔法爆發威脅敵方法師／AP刺客的單次爆發才是主要死亡來源時。

    魔提斯深淵提供魔防與低血量魔法護盾，比單純增加輸出更能保住進場或持續輸出。

  • 爆發對局符文對面主要靠短時間連段把你秒掉，而且目前標準符文沒有骨甲時。

    骨甲直接降低同一名敵人接續幾次技能或普攻的傷害。

控制多高優先

觸發：進場或搶物件時經常被控制鏈直接中斷節奏。

  • 關鍵硬控解法敵方有 1～2 個關鍵硬控，只要命中就可能直接死亡時，將後期彈性位改成水星彎刀。

    先購買水銀飾帶取得主動解控，之後再合成水星彎刀；水銀飾帶是合成組件，不是另一件要與水星彎刀互換的成裝。

  • 重控制陣容控制來源很多，不是只靠一次主動解控就能解決時。

    犧牲部分輸出型傳奇符文，換取韌性與緩速抗性。

治療／吸血多中優先

觸發：敵方前排、鬥士或吸血核心能在物件團長時間回復。

  • 重創需求敵方有多名高治療／高吸血英雄，或核心前排能在團戰中大量回血時。

    生化龐克鏈鋸之劍提供物攻、生命與技能加速，適合近戰物理角色補重創。

我方缺前排中優先

觸發：我方陣容沒有可靠第一承傷點，團戰需要有人更早進場吸收注意力。

  • 提高進場承傷我方完全沒有穩定前排，而你本身就是能進場的近戰鬥士時。

    史特拉克手套用生命與低血量護盾增加第一波承傷，讓你能暫時扛起半前排角色。

提醒：「缺前排」不代表所有打野都要改坦裝；刺客、法師與射手打野硬轉坦通常會失去英雄價值。
