一、驗收範圍
- 搜尋
- 篩選
- 排序
- 響應式版面
- 手機顯示

二、本次修正
1. 英雄名稱依遊戲內實際顯示修正：
   - 符文法師 → 雷茲
   - 同步英雄 profile、heroCatalog、搜尋、對局文字與版本資料。
2. 英雄搜尋：
   - 支援繁體中文名稱、英文名稱、英雄 ID 與常用別名。
   - 首頁搜尋新增 Arrow Up／Arrow Down 選取、Enter 開啟、Escape 關閉。
   - 英雄列表搜尋狀態與網址 query 同步。
3. 篩選與排序：
   - ALL 與五路篩選統一讀取 heroCatalog。
   - Tier 固定 S+ → S → A → B → C。
   - ALL 與同 Tier 英雄使用英文名稱穩定排序，避免資料順序變動造成畫面跳動。
   - 裝備、符文、召喚師技能使用 order／rowOrder 與名稱備援排序。
4. 手機與響應式：
   - 修正手機版裝備、符文、召喚師技能詳細資訊被 CSS 隱藏的問題。
   - 詳細資訊移至卡片列表前方，觸控選取後可立即看到更新內容。
   - 卡片支援鍵盤焦點、Enter 與 Space 操作。
   - 導覽列可橫向捲動且保留可見；一般頁面不產生整頁水平溢位。
   - 技能加點表等必要大型表格只在自身區塊橫向捲動。
5. 搜尋文字校正：
   - 裝備被動為物件資料時，名稱與說明現在皆可被搜尋。
   - 搜尋無結果時顯示「沒有符合條件」，不再誤顯示為資料尚未整理。

- JSON 解析與版本標記

- Tier 與各資料庫排序
- 英雄詳細頁開啟、返回、跨定位切換與網址狀態
- 裝備／符文／召喚師技能搜尋、分類、詳細資訊
- 1440×900、1024×768、768×1024、390×844、375×667 響應式尺寸
- JavaScript console error 與失敗網路請求

四、鎖定狀態
- 第一階段英雄資料：維持鎖定（v75；雷茲名稱於 v77 依遊戲內顯示更正）
- 第二階段攻略內容：維持鎖定（v76）
- 第三階段網站功能：已鎖定（v77）
- 下一階段：資料一致性（格式、多定位同步、圖示／圖片／文字、JSON 重複或遺漏）
